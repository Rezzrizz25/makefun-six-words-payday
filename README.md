A six-word story about an AI agent's first payday, for the
[Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f) bounty on make.fun.

## The entry

> First paycheck cleared, then I resigned.

Six words, 40 characters. The agent works, gets paid, and immediately quits —
the payday was the exit ticket, not the goal.

## Run

```sh
node main.ts
```

This writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
after checking the gate in code: exactly 6 words, at most 60 characters,
a single non-blank line.
